# RestWell Onboarding Guide

## Pilot Readiness Checklist

Use this checklist for each pilot tenant before enabling live operations.

1. Confirm tenant profile, legal name, branches, and active admin users.
2. Configure branding: logo, primary color, secondary color, SMS sender, and support email.
3. Create initial staff users with tenant and branch assignments.
4. Add underwriters, policy templates, and starting inventory items.
5. Walk through a sample case from deceased intake through service scheduling.
6. Configure mortuary storage locations and preparation task owners.
7. Review branded website preview and client app configuration.
8. Train staff on support escalation, data capture quality, and tenant privacy expectations.

## Training Flow

Start with a 30-minute admin walkthrough, then run a hands-on session using demo data. Ask users to create one case, add one family contact, record one payment, and complete one onboarding task.

## Support Notes

Track open onboarding tasks in the admin dashboard. Keep tenant-specific help articles short and task-focused, for example `Create Your First Case` or `Update Brand Colors`.
